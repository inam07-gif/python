
# Unsupervised Learning — Implementation Basics

This folder contains the **initial implementation stage of Unsupervised Machine Learning algorithms**.

For each algorithm, I will explore two approaches:

* **Using Scikit-learn:** Understanding how the algorithm is implemented using `sklearn` and learning to apply it to datasets.
* **From Scratch:** Implementing the core algorithm manually to understand how it actually works internally, without relying on a pre-built machine learning implementation.

The focus here is on **understanding the algorithm through implementation**, starting from the basics and gradually improving the code, efficiency, and understanding as I progress.
